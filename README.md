# Форма регистрации

Учебный фронтенд-проект формы регистрации на **HTML, CSS и JavaScript**. Форма проверяет данные прямо в браузере; сервер и база данных не используются.

## Возможности

- Проверка российского номера телефона: после удаления пробелов и разделителей остаётся **11 цифр**, номер начинается с `7` или `8`.
- Проверка пароля: минимум **8 символов** и оценка сложности не ниже средней по правилам проекта.
- Индикатор сложности пароля: слабый, средний или сильный.
- Подтверждение пароля **с учётом регистра**.
- Блокировка кнопки регистрации, пока данные некорректны, и подсказки об ошибках при вводе.
- **Новая функция:** иконки глаза внутри каждого поля пароля позволяют независимо показать или скрыть пароль и его подтверждение.
- Сообщение об успешной проверке формы при нажатии на кнопку регистрации.

## Запуск

Никаких зависимостей, установки пакетов и сборки не требуется.

1. Сохраните файлы `index.html`, `style.css` и `script.js` в одной папке.
2. Откройте `index.html` в браузере.
3. Введите телефон, пароль и подтверждение пароля. Нажимайте на иконку глаза в нужном поле, чтобы отдельно показывать или скрывать его содержимое.
4. После корректного заполнения нажмите «Зарегистрироваться».

## Исправленный баг

Ранее функция `doPasswordsMatch` приводила оба введённых пароля к нижнему регистру (`toLowerCase()`). В результате значения `Password123` и `password123` ошибочно считались одинаковыми.

**Исправление:** пароли сравниваются строго через `===`, без изменения регистра.

Это **демонстрационная форма**, а не полноценная регистрация: данные никуда не отправляются, аккаунт не создаётся, а сообщение об успехе означает только прохождение клиентской проверки. Для реального сервиса необходимы серверная валидация, защищённая передача данных и безопасная обработка паролей.
